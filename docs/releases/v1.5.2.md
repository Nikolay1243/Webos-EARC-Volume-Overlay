## Overlay size setting

- The setup screen has a new **Overlay size** row: Small, Medium or Large. Large is the original size.
- Choosing a size saves it and immediately previews the overlay at that size. The choice is kept across restarts and upgrades.
- Use the remote's arrow keys to move between the button rows.

### Upgrading

Install the 1.5.2 IPK over the previous version. Open **eARC Volume Overlay** to pick a size; no restart of the watcher is needed.
