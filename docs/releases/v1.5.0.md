## Native watcher and instant overlay

- Replaces the Node.js background watcher with a small static Rust binary (about 400 KB on disk, about 2-3 MB of memory instead of tens of MB). The Node.js watcher stays in the package as an automatic fallback.
- Reads the soundbar's own HDMI-CEC Report Audio Status messages (`RX507Axx`) straight from `/var/log/cecmessages` as they are written (inotify), instead of polling the ARC getter. No processes are spawned per update, and changes made with the soundbar's own remote appear at once.
- Mute now comes from the mute bit in the soundbar's report, not from the TV's mute flag.
- A volume key press shows the overlay immediately with the last known level, dimmed. The soundbar's reply (about 600 ms later on a Polk Signa S4) fills in the confirmed number.
- The overlay app stays resident, hidden, after it fades out. Relaunching a running app is near-instant, whereas a cold web-app start takes 1-2 seconds.
- Reports that arrive right after switching to ARC (wake, input change) update the value silently instead of popping up the overlay.

### Upgrading

Install the 1.5.0 IPK, open **eARC Volume Overlay** and select **Enable**. Enable now restarts a running watcher, so the native one takes over without a reboot.

### Compatibility

The CEC log format was confirmed on an LG C3 with a Polk Signa S4. Other TVs may log differently; the log shows which watcher started (`earc-watcher 1.5.0 starting`). Keeping the overlay app resident costs the web runtime's memory for that app while the TV is on.
