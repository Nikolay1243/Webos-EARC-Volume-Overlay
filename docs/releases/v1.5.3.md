## No stale numbers when the soundbar never reports its volume

Some soundbars accept the TV's volume keys but never report the resulting level. On an LG C2 with a Samsung HW-Q990B, the soundbar sends one volume report at power-on and nothing afterwards, so 1.5.2 kept showing that first number.

- The watcher now keeps counting key presses the soundbar does not answer, even after it has seen a report. Two unanswered presses in a row turn on the fallback that reads webOS's stored soundbar volume, instead of a single power-on report disabling it for good.
- When no source confirms two presses in a row, the overlay stays hidden for key presses rather than repeating an old number. It comes back as soon as the soundbar reports a value or the stored value changes.
- In that state the fallback checks only once per burst of key presses and every 10 seconds otherwise.
- The first value read by the fallback is taken as a baseline, never as a change.

Soundbars that answer every key press (such as the Polk Signa S4 on an LG C3) behave exactly as before.
